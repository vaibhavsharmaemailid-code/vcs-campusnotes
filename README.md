# CampusNotes

A simple notes project for campus students, built to practise Git and GitHub collaboration.

## Project Overview

CampusNotes is a small academic project focused on campus notes and learning version control through Git and GitHub.

## Repository Contents

| File | Description |
|---|---|
| README.md | Project overview and documentation |
| vcs_assignment.txt | Version Control System assignment notes |

## Project Purpose

The project aims to:

- Organize notes and related academic content.
- Practise Git and GitHub collaboration.
- Understand repository management.
- Learn branching, commits and version control workflows.

## Learning Objectives

- Create and manage Git repositories.
- Work with branches and remote repositories.
- Understand collaborative development.
- Practise maintaining project documentation.

Contributions can be made through feature branches and pull requests.
